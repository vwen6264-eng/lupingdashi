# 录屏大师

一款基于 Chrome 扩展 Manifest V3 的录屏与视频编辑工具，支持录制浏览器标签页、屏幕或窗口，并提供自定义区域录制和动效编辑工作台。

## 功能

- 录制当前标签页、屏幕或窗口，以及自定义区域。
- 可选摄像头人像小窗。
- 独立提词器窗口，支持文稿保存、自动滚动及速度、字号调整。
- 编辑器提供自动缩放、3D 动效、标注、背景和视频剪辑与导出功能。
- 使用 `Alt+S` 快捷键开始或停止录制。

## 安装

1. 下载本仓库文件并解压到一个文件夹。
2. 在 Chrome 打开 `chrome://extensions/`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的文件夹。

## 使用

点击浏览器工具栏中的“录屏大师”，选择录制模式，按需开启摄像头，然后开始录制。停止录制后进入编辑器；也可以从扩展弹窗直接打开编辑器。首次使用时，请按浏览器提示授予所需的屏幕或摄像头权限。

勾选“录制麦克风声音”可将默认麦克风与画面声音混合录入。首次使用时，按提示在授权页面允许使用麦克风，再返回扩展开始录制。标签页录制会采集标签页声音；录制屏幕或窗口时，请在浏览器的共享对话框中选择共享音频（可用选项因系统和共享内容而异）。若编辑器未自动播放，请点击播放按钮。

录制前可分别调节麦克风和画面声音音量；混音后无法再单独调整。标签页和框选录制可在编辑器中更换鼠标样式，屏幕或窗口录制使用原始鼠标。合成视频输出为 1080p，实际清晰度仍取决于录制源。

在扩展弹窗点击“打开提词器”，输入文稿后点击“置顶提词器”，即可在录制时继续查看并调整。点击“开始提词”自动滚动，可调整速度和字号，播放时按空格暂停或继续。置顶使用浏览器的文档画中画功能；录制整个屏幕时，提词器可能出现在录制画面中。

在 Chrome 中按 Alt+Shift+P 可打开提词器；快捷键可在 `chrome://extensions/shortcuts` 中修改。编辑器支持 Ctrl+Z 撤销编辑，视频与录音同步播放；点击“全屏工作台”可切换全屏。

录制桌面软件时，请选择“全屏/窗口”，然后在选择框中选择目标屏幕或软件窗口。桌面软件的鼠标轨迹和点击事件无法由浏览器扩展采集，因此该模式无法添加跟随鼠标的点击特效；网页鼠标特效请使用“当前标签页”或“自定义区域”模式。

## 项目结构

- `manifest.json`：扩展配置与权限。
- `popup.html`、`popup.js`：录制控制界面。
- `sw.js`、`offscreen.html`、`offscreen.js`：后台与录制处理。
- `content.js`：页面交互。
- `editor.html`、`editor.js`：视频编辑工作台。
