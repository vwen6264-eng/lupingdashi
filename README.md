# 录屏大师

一款基于 Chrome 扩展 Manifest V3 的录屏与视频编辑工具，支持录制浏览器标签页、屏幕或窗口，并提供自定义区域录制和动效编辑工作台。

## 功能

- 录制当前标签页、屏幕或窗口，以及自定义区域。
- 可选摄像头人像小窗。
- 编辑器提供自动缩放、3D 动效、标注、背景和视频剪辑与导出功能。
- 使用 `Alt+S` 快捷键开始或停止录制。

## 安装

1. 下载本仓库文件并解压到一个文件夹。
2. 在 Chrome 打开 `chrome://extensions/`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的文件夹。

## 使用

点击浏览器工具栏中的“录屏大师”，选择录制模式，按需开启摄像头，然后开始录制。停止录制后进入编辑器；也可以从扩展弹窗直接打开编辑器。首次使用时，请按浏览器提示授予所需的屏幕或摄像头权限。

## 项目结构

- `manifest.json`：扩展配置与权限。
- `popup.html`、`popup.js`：录制控制界面。
- `sw.js`、`offscreen.html`、`offscreen.js`：后台与录制处理。
- `content.js`：页面交互。
- `editor.html`、`editor.js`：视频编辑工作台。
